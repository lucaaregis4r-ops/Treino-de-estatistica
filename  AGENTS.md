# Agent Instructions

This file contains instructions for the AI agent when working in this repository.

## Common Commands
- `npm run dev` - Start development server
- `npm run build` - Build the project
- `npm run lint` - Run linter
- `npm run typecheck` - Run type checker

## Project Structure
- This is a TypeScript/React project
- Source files are under `src/`
- Component screens are under `src/ui/screens/`

## When Editing Code
1. First read the relevant file(s) to understand the current code
2. Make precise edits using the edit tool
3. Verify changes don't break existing functionality
4. Run lint/typecheck if available
