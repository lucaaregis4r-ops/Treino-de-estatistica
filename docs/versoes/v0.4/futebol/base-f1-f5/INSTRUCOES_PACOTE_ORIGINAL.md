# Scout Trainer Futebol — como retomar depois

1. Extraia este RAR **na raiz do checkout local** de `Treino-de-estatistica`. Os arquivos ficarão em `docs/versoes/v0.4/futebol/base-f1-f5/`.
2. Abra o projeto no Codex/Luna. Peça a leitura de `AGENTS.md`, `docs/versoes/v0.4/futebol/base-f1-f5/Scout_Trainer_Futebol_Plano_0_1_Luna.md` e de `docs/versoes/v0.4/futebol/base-f1-f5/Scout_Trainer_Futebol_F1_Base_StatsBomb.md`.
3. Copie o bloco **Prompt para Luna** ao final da F1. Execute apenas essa etapa e confira o resultado no aplicativo.
4. Depois use, uma por solicitação, os prompts de F2, F3, F4 e F5, sempre com `ESTADO.md` atualizado. O checkout local e seu código são a fonte de verdade.

A ordem foi pensada para deixar o projeto executável ao final de cada etapa. O RAR contém **o plano de implementação**, não o código da funcionalidade nem os dados públicos completos da StatsBomb. A F5 orienta como obter e derivar o recorte de referência documentado.
